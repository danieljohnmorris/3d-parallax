# 3D Parallax Mountain Valley

A scroll-driven Three.js scene where the camera descends from above a mountain range into a valley. Two versions: v1 is terrain and fog, v2 adds trees, water, a sky shader, shadows, and post-processing.

**Live demo:** [3d-parallax.danieljohnmorris.com](https://3d-parallax.danieljohnmorris.com/)
